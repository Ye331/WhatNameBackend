# 功能范围与验收

系统采用 RBAC0 模型管理用户、角色、菜单和 API 权限，同时通过管理员任命、等级和部门范围约束管理操作。

| 功能 | 规则 |
| --- | --- |
| 账号与登录 | 支持账号或手机号密码登录、短信设密、密码重置、会话注销及临时账号管理。密码使用scrypt哈希；姓名和手机号按明文演示数据存储，手机号参与防篡改签名。 |
| 资源与角色 | 维护应用、菜单、API及其关联；通过角色菜单配置和用户角色来源形成有效权限。 |
| 在线鉴权 | 根据当前账号状态、部门状态、有效授权来源和数据签名判断权限，记录用户、目标、结果、原因、时间及关联编号。 |
| 管理员 | 一级管理员为范围内较低等级管理员直接配置可授权角色清单；管理操作同时检查功能权限和部门范围。 |
| 批量操作 | 每次1–100位用户，同步执行，逐人独立事务，直接返回全部结果；明确业务失败可修正后重试，结果未知时先查询实际授权状态。 |
| HR/OA事件 | 按来源和事件编号去重，拒绝同号不同内容；HR对象版本递增；事件登记、业务变更与成功结果在同一事务提交，失败回滚。 |
| 组织管理 | 支持部门同步、合并、冻结和解冻；管理员本人调岗或离职时撤销其任命并清空其清单。 |
| 审计与安全 | 提供操作、鉴权、登录日志及审计详情查询；使用数据签名、日志封印、服务请求签名和nonce防重放。 |
| 初始化与恢复 | 支持受控初始化和超级用户权限恢复；数据库使用手动完整备份和独立库恢复验证。 |

## 功能验收

1. 登录取得JWT；无效或已注销令牌不能访问受保护接口。
2. 建立应用、菜单、API和角色关联，授予后鉴权允许。
3. 回收最后一条有效授权来源后鉴权拒绝；存在其他有效来源时角色保持有效。
4. 一级管理员配置下级清单；范围外操作及无资格的清单配置被拒绝。
5. 同步批量逐人返回结果；超过100人被拒绝；单人的业务失败不回滚其他人的成功。
6. 成功HR/OA事件重复提交返回相同结果；同号异内容、无效版本或服务签名被拒绝。
7. 管理员本人调岗或离职撤销其任命；普通人员调入不撤销接收部门管理员。
8. 冻结影响业务权限，解冻后按有效授权计算；数据篡改时验签拒绝。

## 备份与恢复

停止写入后，使用MySQL的mysqldump完整导出数据库，密码通过交互方式输入。备份文件与签名密钥保存在仓库外。恢复时先导入单独的数据库，修改本地连接配置并验证登录、授权及鉴权结果，确认后再使用恢复数据。
