### 已覆盖的关键场景

1. 新任务返回 202/PENDING，执行前没有授权变更；后台完成后数据库和接口均返回真实结果。
2. 正式线程池自动执行，无需测试手动触发；后台线程没有请求身份 ThreadLocal，仍使用可信任务发起人完成授权。
3. 完全重复目标合并、顺序调整重放、同键不同内容冲突；并发相同请求只创建一个任务，重复工作线程不重复授权、递增版本或写成功审计。
4. 合法目标与不存在目标混合时部分成功；同键重放不重新执行失败项，修正后使用新键仅提交失败目标可成功。
5. 批量精确回收一项来源时保留独立来源和有效角色关系；持久结果包含最新授权版本。
6. 签名或审计写入后抛错：来源、关系、用户版本、签名和审计一起回滚，另行保存失败结果。
7. APPLIED 写入被数据库拒绝：业务及证据全部回滚，任务项保持待处理，同键重放不自动恢复。任务项插入失败时，任务本身也回滚且不调度。
8. 提交后撤销发起人任命，执行项因当前资格失效而失败；详情按当前查看人的范围先过滤再分页，计数不包含不可见目标。
9. 调度被拒绝时任务和输入仍已持久化，结果可查询，未执行项不误报成功。
10. 非法字段、真实数值 ID、非法布尔类型、缺少幂等键、非法键字符／长度、空目标、混用操作字段、非法分页和默认未认证访问均被拒绝。
11. 原有单人版本冲突、并发授权、等待后资格复核、多来源、空集合签名等回归测试全部通过。

数据库故障通过**隔离临时库中的 CHECK 约束**注入，测试结束即移除；没有修改正式建表脚本或放宽数据库权限。
