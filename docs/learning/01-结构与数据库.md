# 1. 三层结构与数据库

固定技术栈：Java 21、Spring Boot、Spring Data JPA/Hibernate、MySQL、Vue 3。

以修改用户角色为例：ManagementController.userRoles 接收 userId 和 roleIds → GrantService.replace 检查权限与部门范围 → DomainRepository 读写关联实体 → SignatureService 和 AuditService 随同提交。

Controller 不写 SQL，不判断部门关系；Repository 不判断谁是管理员。Service 负责业务规则和事务。

## 11 张表怎么记

- 人与组织：sys_user、sys_dept。
- 资源：sys_application、sys_menu、sys_api、sys_menu_api。
- RBAC：sys_role、sys_user_role、sys_role_permission。
- 支撑：sys_data_signature、sys_operation_log。

Domain.java 中的每个 @Entity 对应一张表。AccountRepository 继承 JpaRepository；DomainRepository 使用 EntityManager 和 JPQL 做关联查询、分页和行锁。仍然是 JPA/Hibernate，不是把业务改成 JDBC。

关系表只存双方 ID。组合唯一约束阻止重复关联，外键阻止引用不存在的对象。日志不依赖业务外键，以便保留历史。

练习：在 schema.sql 中找到“一个用户可以有多个角色、一个角色可以给多个人”的两个外键和组合唯一约束。
