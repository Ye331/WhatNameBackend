# 8. 前端与答辩分工

App.vue 处理登录和导航，api.js 处理请求及内存会话；views 下对应用户、角色、资源、组织、日志和业务演示。EditDialog 和 DataTable 是共用组件。

前端 can(code) 仅决定菜单/按钮是否显示。真正鉴权在后端，不能因为按钮隐藏就省略服务端校验。保存操作后刷新本人权限；页面失去权限时会切换到仍可访问的页面。

JWT 不存 localStorage。首次使用员工账号、忘记密码均由管理者重置，不再显示短信页面。

## 七人建议分工

| 同学 | 主讲内容 | 主要源码 |
|---|---|---|
| A | 账号、临时人员、密码、会话 | AccountService、JwtTokenService |
| B | RBAC0 与平台自我管理 | AccessService、ManagementInterceptor |
| C | 应用、菜单、API | ResourceService 的资源方法 |
| D | 角色、授权及同步批量 | ResourceService 的角色方法、GrantService、BatchService |
| E | 部门树、范围与冻结 | AccessService.within、OrganizationService.freeze |
| F | HR/OA、调岗离职合并 | IntegrationController、OrganizationService |
| G | 签名、日志、初始化与测试 | SignatureService、AuditService、InitializationService |

所有人都应掌握数据库主链和三层职责。能讲清楚：谁有权限、允许什么接口、能管哪些人、撤权何时生效、事务失败如何回滚。
