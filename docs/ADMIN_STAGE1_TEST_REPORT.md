# 管理员模块第一阶段测试报告

验证日期：2026-10-14（Asia/Shanghai）。本地分支：`feat/admin-rules-maintenance`；基线：`dd9a0e5`。本次修改保留在本地工作区，未提交、推送或创建 PR。

## 完成内容

- 管理员列表、任命、撤销、本人管理范围、可委派角色清单查询和全量替换，共 6 个接口。
- 管理等级与部门子树校验、角色可委派检查、清单版本冲突处理、下级清单递归收缩，以及重任命处理。
- 可供其他模块复用的事务内管理规则检查，身份、功能权限、签名及审计接入点；依赖未接入时默认拒绝。
- MyBatis 数据访问、严格 JSON 类型校验、事务开启失败的 503 响应。沿用现有数据库结构，没有修改建表脚本。

临时业务口径、接入要求和锁范围限制见 [模块说明](ADMIN_STAGE1.md)。

| AdminIT | 8 | 真实 MySQL 映射、事务及并发 |

集成测试使用与 Compose 相同摘要的 MySQL 8 镜像，在 Testcontainers 临时数据库中执行仓库原始建表脚本。覆盖以下场景：

1. 任命、列表、撤销的真实 SQL 映射。
2. 下级清单递归收缩、版本递增及既有用户授权保留。
3. 审计写入后失败时，清单、下级变更、版本和审计记录全部回滚。
4. 签名接入失败时任命回滚。
5. 重新任命清空旧清单并收缩相关下级清单。
6. 相同版本并发替换，仅一个成功，另一个返回版本冲突。
7. 撤销事务与清单修改并发时，等待锁后重新检查资格并拒绝失效操作者。
8. 共享检查入口拒绝无事务调用，已有事务内可正常使用。

未连接或修改既有开发数据库。测试身份及故障注入仅位于测试源码；打包产物检查未发现这些测试类。
