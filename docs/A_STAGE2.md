# A 第二阶段：现有协作能力适配与联调

任务分支：`feat/a-stage2-integration`。

依据[两阶段开发计划](../DEVELOPMENT_PLAN.md)，本阶段在[第一阶段基础功能](A_STAGE1.md)上接入既有协作能力并推进联合验证。本文只记录第二阶段增量、使用方式和当前依赖；已执行结果见[第二阶段测试报告](A_STAGE2_TEST_REPORT.md)。当前完成的是 A 能独立实现的适配，完整 Stage2 尚未验收。

## 1. 已完成的 A 侧适配

| 能力 | 当前实现 |
|---|---|
| 独立模拟短信 | 复用既有 SmsSender；显式演示配置下将验证码投递到仓库外目录，不增加取码 HTTP 接口 |
| A 请求身份 | ARequestIdentity 实现既有 AdminPorts.Identity，从当前请求 JWT 验签取得操作者；不提前建立数据库读视图，不自动装配不完整的 C 生产链路 |
| A 对 D 安全适配 | DBackedManagementDataSecurity 复用 D 既有 DataSignatureService、PermissionService.requireFunction 和 AuditService，验证完整事实与 A 当前使用对象一致 |
| 账号与会话 | 新账号同事务建立身份及空授权集合签名；旧账号缺签名拒绝，不在读取时补签。注销先校验身份完整性，再撤销会话并记录审计 |
| HR 人员与组织 | 覆盖 HR01—HR05 的 A 业务变更、人员 / 部门 / 组织签名和操作审计；C 所有的授权修订与集合签名由 C 处理，A 验证最终结果 |
| 外部事件 | 写事务锁定事件后复用既有可信服务校验，为当前事务绑定正在执行的事件、操作和目标，阻止伪造或跨事务上下文取得签名权限 |

签名、关键审计、业务事实及事件 APPLIED 同事务提交，任何失败均回滚。合并为每名迁移用户保存身份变更证据，部门审计仅保留受影响部门与迁移人数，关联同一事件；证据不传入姓名、手机号或凭据。

沿用团队现有数据库、HTTP 接口及 C/D 既有协作接点。必要提供者缺失时继续拒绝；内部事件执行凭据不替代 D 服务认证、请求签名、范围绑定及 nonce 校验。非终态在线恢复仍返回 503，不增加自动接管入口。

## 2. 演示短信使用

本地演示先创建一个仓库外的绝对目录，在 IDEA 的 Program arguments 中设置：

```text
--spring.profiles.active=sms-demo --iam.sms.demo-directory="<仓库外已存在的本机绝对目录>"
```

`LocalDemoSmsSender` 将验证码投递到该目录，文件名为规范手机号 SHA-256 小写十六进制摘要加 `-SET_PASSWORD.sms` 或 `-RESET_PASSWORD.sms`，内容仅含 `code` 和 UTC `expiresAt`。演示者在本机读取对应文件，再调用原有设密 / 重置接口；验证码不写业务日志或正式 HTTP 响应。验证码有效期、错误次数及一次核销仍由数据库判定。

模拟目录不得位于 Git 工作树内或经过链接路径。未启用 `sms-demo`、目录未准备或不可写时不发送，返回 `SMS_DELIVERY_UNAVAILABLE`。演示文件及个人启动配置不提交仓库；该通道不需要商业短信账号。

本地文件投递不参与数据库事务；审计或业务回滚后即使文件已存在，其中验证码也不能通过数据库校验。手机号和验证码不写入业务日志，文件及个人启动参数不提交仓库。现有通道可被团队后续提供的发送实现替换。

## 3. 当前待配合事项

| 责任方 | 事项及影响 |
|---|---|
| C | 补齐旧岗位来源精确回收、离职全回收、复职资格、调岗及组织重审，以及 C 自有任命 / 授权入口的合并部门限制；对应 HR 生产协作尚不可用 |
| A、C、D | 联合装配现有管理接点，在取得管理锁后复核当前账号、session_version、jti 和功能权限；A 身份实现已提供，尚不能据此启用缺少锁后复核的链路 |
| D | 提供 HR / OA 等服务身份、应用与操作范围绑定、请求签名及 nonce 防重放；普通 HR 请求目前仍不能凭 sourceSystem 或构造上下文通过认证 |
| 团队共同 | 确认受控账号 / 签名初始化、原始员工全量导入、人工异常事件处理，完成自身 IAM 与演示系统的完整权限链路及安全、并发、性能验收 |

HR / OA 使用测试请求模拟外部系统，不需要建设企业人事或审批平台；模拟请求仍执行规定的认证、签名和防重放。演示采用独立模拟短信，商业短信供应商账号不是当前功能开发的前置依赖。全量员工导入和完整链路尚未验收，局部测试不能替代团队验收。
