## 2. 演示短信使用

本地演示先创建一个仓库外的绝对目录，在 IDEA 的 Program arguments 中设置：

```text
--spring.profiles.active=sms-demo --iam.sms.demo-directory="<仓库外已存在的本机绝对目录>"
```

`LocalDemoSmsSender` 将验证码投递到该目录，文件名为规范手机号 SHA-256 小写十六进制摘要加 `-SET_PASSWORD.sms` 或 `-RESET_PASSWORD.sms`，内容仅含 `code` 和 UTC `expiresAt`。演示者在本机读取对应文件，再调用原有设密 / 重置接口；验证码不写业务日志或正式 HTTP 响应。验证码有效期、错误次数及一次核销仍由数据库判定。

模拟目录不得位于 Git 工作树内或经过链接路径。未启用 `sms-demo`、目录未准备或不可写时不发送，返回 `SMS_DELIVERY_UNAVAILABLE`。演示文件及个人启动配置不提交仓库；该通道不需要商业短信账号。

本地文件投递不参与数据库事务；审计或业务回滚后即使文件已存在，其中验证码也不能通过数据库校验。手机号和验证码不写入业务日志，文件及个人启动参数不提交仓库。现有通道可被团队后续提供的发送实现替换。
