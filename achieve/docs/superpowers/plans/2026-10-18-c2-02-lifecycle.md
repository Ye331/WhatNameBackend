# C2-02 管理员与组织生命周期实施步骤

**Goal:** 在 `feat/c-stage2-integration` 保留 C2-01 的真实签名、会话及锁序基线，补齐合并生命周期与组织变更后的范围重审。管理角色等级未获团队规则，用户已确认继续默认拒绝。

**Architecture:** 沿用 Service → Mapper；读取现有 `merged_into_dept_id`，不增加数据库字段或 HTTP。组织事件在事件锁后、组织/用户操作前准备 C 当前锁与验签快照；既有 `organizationChanged` 执行限制和重审。A 继续负责事件认证、组织/人员最终签名和事件结果；C 仅签管理员事实、记录重审证据。内部协作增加准备阶段，缺少该阶段必须拒绝。

**Tech Stack:** Java 21、MyBatis、JUnit、MySQL Testcontainers、真实 D 签名审计。
